# Grana — versões para instalar

Grana é um app de finanças pessoais. Os dados ficam só no aparelho.

Este repositório guarda **apenas as versões prontas para instalar**. O código fica em outro lugar.

## Como instalar
Abra a [versão mais recente](https://github.com/Rycks012/grana-releases/releases/latest) e baixe:
- **Celular (Android):** o arquivo `.apk`. Uma versão nova instala por cima da anterior, sem apagar os dados.
- **Computador (Windows):** o `.msi` ou o `.exe`. Substitui a versão anterior.

A partir da versão 0.5.4, o próprio app avisa: em **Novidades → Verificar atualização**.

## Para o app
`latest.properties`, anexado a cada versão, diz qual é a mais nova, com os links e o SHA-256 de cada arquivo. O app lê esse arquivo só quando o usuário toca em "Verificar atualização".
