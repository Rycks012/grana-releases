# Prumo — versões para instalar

**Suas contas no prumo.** Prumo (antes chamado Grana) é um app de finanças pessoais que mostra o previsto e o realizado lado a lado. Os dados ficam no aparelho e, se você entrar numa conta, no seu próprio servidor.

Este repositório guarda **apenas as versões prontas para instalar**. O código fica em outro lugar.

## Como instalar
Abra a [versão mais recente](https://github.com/Rycks012/prumo-releases/releases/latest) e baixe:
- **Celular (Android):** o arquivo `.apk`. Uma versão nova instala por cima da anterior, sem apagar os dados.
- **Computador (Windows):** o `.msi` ou o `.exe`. Substitui a versão anterior, inclusive o Grana.

**Vindo do Grana no celular:** o Prumo é instalado como um app novo, ao lado do Grana. Entre com a sua conta no Prumo (os dados chegam pela sincronização) ou restaure um backup do Grana; depois, desinstale o Grana.

O próprio app avisa quando há versão nova: em **Novidades → Verificar atualização**.

## Para o app
`latest.properties`, anexado a cada versão, diz qual é a mais nova, com os links e o SHA-256 de cada arquivo. O app lê esse arquivo só quando o usuário toca em "Verificar atualização".
